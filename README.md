# 作业批改系统

一个面向中小学的 .NET 课程项目，计划利用大模型辅助批改语文、数学、英语、历史等科目的作业，减轻教师的批改负担。

## 初步范围

- 作业管理、作业批改接口及相关操作界面。
- 注册登录、角色权限和数据库设计。
- 后续可扩展学生、教师、家长、课程与班级管理等功能。

## 当前状态

项目处于文档筹备阶段，尚未开始正式开发。需求、技术方案和支持平台待讨论。
