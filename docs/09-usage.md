# 使用手册

## 前端样式预览

按[开发环境](06-development/01-setup.md#启动前端样式预览)启动，打开后默认进入教师工作台。可筛选或翻阅作业列表，点击「去批改」打开双栏批改页；点击右上角「切换学生端」即可浏览作业、试用文本提交和查看样例成绩。

当前界面使用演示数据，操作只影响当前页面预览；未接入登录、后端 API 或真实模型。

## 后端接口试用

后端开发实例支持通过 Swagger 试用。按[开发环境](06-development/01-setup.md)启动后访问 `http://localhost:5080/swagger`。同一浏览器会保留登录会话。接口具体字段、写请求头和错误处理见[API 手册](04-api.md)。

默认开发配置在空库初始化演示数据。演示账号为 `teacher@example.test`、`student@example.test`，密码都是 `Demo123!`。这两个账号对应不同角色。每次切换角色可在 Swagger 再次登录，也可使用两个独立的浏览器配置。

1. 用教师账号调用登录接口，再调用作业发布接口。截止时间填写未来时间，保存发布响应中的作业 `id`。
2. 用学生账号登录，打开该作业详情，提交文字答案，保存响应中的提交 `id`。
3. 切回教师账号，打开作业详情查看提交摘要，再打开具体提交。输入分数和反馈并保存。
4. 切回学生账号，打开作业详情，在 `mySubmission` 读取成绩与反馈。

测试过程中遇到 `401` 可重新登录。作业已有提交后会锁定修改与删除，评分可重新保存。开发服务可用 `Ctrl+C` 停止，重启后仍可读取原数据库。正式启动方式见[发布与交付](08-release.md)。
