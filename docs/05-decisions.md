# 技术决策记录

这里记录会影响后续开发、部署或维护的技术选择。当前未确认 SDK 版本、应用框架、数据存储、模型接入方式和发布形态，本机环境信息见 [开发环境](06-development/01-setup.md)。

讨论形成明确方案后，在本页记录。需要拆分多篇时，按 [文档命名约定](01-index.md#维护约定) 建立主题目录，由总索引链接决策入口。每份记录说明：

1. **状态**：提议、已采纳或已替代。
2. **背景**：需要解决的问题、约束和对应的需求或设计。
3. **备选方案**：考虑过哪些方案，主要取舍是什么。
4. **决定与依据**：采用什么，为什么，有哪些验证支撑。
5. **影响**：对开发、运行和迁移的影响，什么情况需要重新评估。

方案变更时保留历史记录，在旧记录中标明替代它的新记录。
