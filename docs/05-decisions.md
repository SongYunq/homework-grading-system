# 技术决策记录

## D-001 · 后端框架与项目结构

状态：已采纳。课程项目使用仓库已有的 mise 环境和 .NET 8 SDK。首版使用 ASP.NET Core 控制器实现 HTTP API，将业务对象和规则放在独立领域项目，将用例与数据访问接口分离。这样接口层可围绕客户端调用演进，业务层无需依赖 Web 框架。项目职责见[后端设计](03-design/01-backend.md)。

## D-002 · 关系数据库

状态：已采纳。首版采用 EF Core 8 和 SQLite，开发机可直接启动，数据库能约束关联数据与唯一性。通过迁移维护表结构。部署规模或并发写入需求变化时，再评估使用独立数据库服务的成本与收益。

## D-003 · 浏览器会话

状态：已采纳。前端按同源方式接入。ASP.NET Core 管理登录 Cookie 及其有效期，前端无需保存凭据或先调用身份检查接口再发业务请求。固定写请求头与同源约束配合使用。需要支持跨域页面、第三方客户端或即时吊销会话时，重新评估认证方案。请求体与错误契约见 [API 手册](04-api.md)。

## D-004 · 外部评分服务

状态：已采纳。模型调用作为可配置的评分建议接口，默认给出 DeepSeek 请求地址和模型名，运行时提供密钥启用。业务通过接口访问评分服务，人工保存批改结果不依赖模型。若更换供应商，先验证其 JSON 输出与超时行为。配置见[开发环境](06-development/01-setup.md)。

## D-005 · React 前端与组件库

状态：已确认 React 与 [TDesign React](https://github.com/Tencent/tdesign-react)。其余为设计草稿：在同一仓库建立一个前端项目，为教师和学生提供各自的布局和路由。使用 TypeScript、Vite、React Router 与 TanStack Query，直接消费现有 API，沿用 D-003。按页面使用 TDesign 组件，教师端参考后台布局，学生端使用轻量页面。具体版本在实现时验证组合兼容性并锁定。页面和状态职责见[前端设计](03-design/02-frontend.md)。
