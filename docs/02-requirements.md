# 需求说明

状态：首版后端已实现。范围以本轮后端任务和[课程原始说明](courseware/作业批改-2026.pdf)为依据。验证方式见[测试与验证](07-testing.md)。

| 编号 | 使用场景 | 首版完成条件 |
| --- | --- | --- |
| `REQ-001` | 注册、登录和访问控制 | 学生可注册和登录，教师由启动配置或开发示例预置。教师只能管理自己的作业和批改这些作业的提交，学生只能查看自己的答案和批改结果。 |
| `REQ-002` | 发布与浏览作业 | 教师填写标题、学科、题目、满分、截止时间，可填写参考答案和评分标准。所有登录学生可浏览已发布作业。参考答案和评分标准只供对应教师查看。有提交后停止修改和删除该作业。 |
| `REQ-003` | 提交与人工批改 | 每位学生可在截止前提交一次文字答案。教师录入分数与反馈，可重新批改。分数在零与满分之间，最多两位小数。学生打开作业即可看到自己的提交和已保存结果。 |
| `REQ-004` | 获取模型批改建议 | 配置模型服务且作业有评分标准时，教师可获取建议分数与反馈。建议由教师确认，正式成绩只在保存批改时更新。人工批改可独立使用。 |
| `REQ-005` | 按页面组织调用 | 作业列表一次返回分页信息与状态汇总。教师打开详情时得到同页提交摘要，学生打开详情时得到自己的提交。前端直接发业务请求，服务端就地认证和授权。具体调用见[API 手册](04-api.md)。 |

后续待讨论：网页实现、班级和课程归属、附件提交、重交、家长与消息。首版学生共享一个作业空间。
