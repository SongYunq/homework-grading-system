## 让其他机器运行

队友需要修改源码时，按 [开发环境](06-development/01-setup.md) 安装约定的 SDK 后构建。如果朋友只需要运行应用，可以在确定目标操作系统、CPU 架构和外部依赖后评估两种发布方式：

| 方式 | 运行方需要准备什么 |
| --- | --- |
| 自包含发布 | 发布包携带 .NET 运行时，按目标平台打包；仍需满足应用的系统和外部依赖。 |
| 依赖运行时发布 | 发布包不携带 .NET 运行时，运行方需安装应用兼容的运行时。 |

以应用在目标机器上的实际验证结果决定支持范围。参考 [Microsoft 的 .NET 应用发布说明](https://learn.microsoft.com/en-us/dotnet/core/deploying/)。
